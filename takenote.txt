Sharing Tab - RBAC Permissions for Actions
==========================================

WHAT WAS DONE:
- Users with update:sharingcontent permission can see Edit button on their own content
- Users with delete:sharingcontent permission can see Delete button on their own content
- Admin (read:sharingcontent:all) can edit/delete ANY user's content
- Non-admin users can only edit/delete content they created (ownership check)

HOW IT WORKS:
1. Frontend loads merged permissions from /permissions endpoint
2. Sets canUpdate, canDelete, hasReadAll, currentUserId states
3. Actions column checks per row: isOwner = record.userId === currentUserId
4. canEdit = hasReadAll || (canUpdate && isOwner)
5. canRemove = hasReadAll || (canDelete && isOwner)

BACKEND CHANGES:
- sharing-content.service.ts: update() and remove() accept hasReadAll param
- sharing-content.controller.ts: checks read:sharingcontent:all permission before calling service
- If hasReadAll = true, ownership check is skipped

SEED PERMISSIONS (for reference):
- read:sharingcontent:all  → ADMIN only (sees all records)
- create:sharingcontent    → Create new sharing content
- update:sharingcontent    → Edit sharing content (own only)
- delete:sharingcontent    → Delete sharing content (own only)

ASSIGNING PERMISSIONS TO A ROLE:
- Go to Roles tab → Assign Users → select user
- Or edit a role → add/update permissions
- Users get their role permissions + any individual permissions

KEY FILES:
- frontend: src/app/(dashboard)/sharing-content/page.tsx
- backend:  src/sharing-content/sharing-content.controller.ts
- backend:  src/sharing-content/sharing-content.service.ts

OTHER RBAC FEATURES BUILT:
- createdBy tracking on User, Role, Permission, SharingContent models
- :all permissions (read:user:all, read:history:all, read:sharingcontent:all) for admin
- Backend filters data by userId for non-admin users
- Self-protection: cannot delete yourself, cannot change your own email via admin endpoint
- Individual permissions modal shows role (fixed) vs individual (editable) permissions
- Users tab hides Create/Roles/Permissions tabs for non-admin
- Sharing tab shows Create button only for users with create:sharingcontent

==========================================

- Removed separate password modal (consolidated into edit)
